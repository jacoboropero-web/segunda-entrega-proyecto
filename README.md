# Estación de Monitoreo Ambiental con Ventilación Automática (ESP32)

Proyecto del curso Diseño Electrónico CAD, Universidad Autónoma de Manizales.
Autores: Jacobo Ropero y Santiago Rueda. Docente: Iván Alberto Arias.

## Contenido

| Carpeta | Contenido |
|---|---|
| `reporte/` | Reporte de Avance 2 (formato IEEE, PDF) |
| `hardware/estacion_kicad/` | Proyecto KiCad 7: esquemático jerárquico (3 hojas), PCB de 4 capas de 80 × 60 mm y librería de símbolos propia |
| `hardware/estacion_kicad/fab/` | Archivos de fabricación: Gerber y taladrado, BOM y CPL para JLCPCB, esquemático en PDF |
| `firmware/` | Firmware preliminar para ESP32-WROOM-32E (PlatformIO/Arduino), con 15 pruebas unitarias de la lógica de control. Ver `firmware/README.md` |
| `imagenes/` | Capturas de KiCad: editor de esquemas, ERC, editor de placas, pistas, ratsnest y vistas 3D |

## Abrir el proyecto

Abrir `hardware/estacion_kicad/estacion.kicad_pro` con KiCad 7 o posterior.
